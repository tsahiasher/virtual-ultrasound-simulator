# Project Progress Log

**2026-08-29 — Phase 4: Basic Ultrasound Appearance Model (offline, code + tests). ✅ DONE**
Implemented a modular B-mode ultrasound acoustic appearance pipeline operating strictly in the polar acquisition domain (`scanLine` × `depthSample`) across both GPU compute and CPU reference backends. Added:
1. **Tissue Properties & Texture3D Encoding:** Added backscattering coefficients to synthetic anatomy materials (Cyst/Fluid: 0.02, Parenchyma: 0.25, Organ: 0.60, Vessel Wall: 0.85) and baked 2-channel `RGBAHalf` volume texture (`R` = Density, `G` = Scattering). Upgraded volume texture to $256 \times 256 \times 256$ with 5-point sub-voxel anti-aliased filtering to eliminate voxel boundary stair-stepping and achieve parity with analytical CPU evaluation.
2. **Boundary & Interface Reflections:** Implemented 3D spatial gradient estimation $|\nabla D|$ from volume density to enhance acoustic impedance boundaries.
3. **3D Spatially Coherent Speckle:** Implemented continuous, deterministic 3D hash noise anchored to world coordinates ($P_W$) with zero frame-to-frame temporal flickering (fine grain `SpeckleScale = 850`).
4. **Polar Acoustic Attenuation & Compression:** Implemented axial beam depth attenuation $\exp(-\alpha \cdot z)$, linear system gain, and logarithmic dynamic range compression $\frac{\ln(1 + C \cdot I)}{\ln(1 + C)}$.
5. **High-Definition Defaults:** Upgraded default ray sampling to **1024 samples per scanline** and display resolution to **512 × 512**, with real-time Inspector rebake support (`OnValidate`).
6. **Debug Inspection Views:** Added `AppearanceDebugView` enum (`FinalUltrasound`, `RawAnatomical`, `BoundaryResponse`, `SpeckleScattering`) cycleable via the **`V`** keyboard shortcut and exposed in the HUD telemetry.
7. **Verification Suite:** Expanded test suite from 18 to 26 passing tests with zero failures, proving boundary gradient enhancement, monotonic attenuation decay, gain linearity, log compression weak-echo boost, 3D speckle stability, fluid cavity low internal scatter, and sector mask preservation.
